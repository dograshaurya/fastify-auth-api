# 🚀 Fastify Auth API (MongoDB + JWT)

A structured, modern, and production-ready Fastify-based authentication API with MongoDB, JWT, and modular architecture.

---

## 📦 Features

- ✅ **Fastify** — lightweight and blazing fast framework
- 🔐 **JWT Auth** — secure authentication with access token
- 🧱 **MongoDB + Mongoose** — flexible schema-based NoSQL database
- 🧩 **Modular Structure** — clean separation of plugins, routes, controllers, models
- 🌱 **.env Config Support** — environment-based configuration
